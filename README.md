## 🏗 Engineering Principles

```text
Request ──▶ Controller ──▶ Service ──▶ Repository ──▶ PostgreSQL
              (routing)    (business     (Prisma ORM)
                             logic)

External Providers ──▶ Raw Data ──▶ Processed Data ──▶ Audit Log
                       (Extract)    (Transform / Load)   (Reconcile)
```

- **Layered Architecture**: strict separation of concerns for maintainability
- **Repository Pattern**: isolated data access, easy to mock and test
- **ETL Pipeline**: staged ingestion from multiple providers with audit logging
- **Automated CI Testing**: every push and PR runs the full unit test suite
